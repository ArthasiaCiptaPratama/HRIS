# BUG-003: Panel lampiran Drive macet bila koneksi menggantung
- **Prioritas:** P2 · **Status:** DITUTUP 2026-10-12 (commit `1eeb205`; rilis gel. 4.1 PR #43/#44, `Deploy staging` #38219815931; Playwright staging B-04b LULUS — coba ulang ±67 dtk) · **Case:** TC-EMP-208 (ditemukan saat uji staging gel. 4, 2026-10-12)
- **Langkah reproduksi:** 1. Login SA di staging. 2. Import `g4-lampiran.csv` (25 baris dummy + 150 tautan Drive palsu) → Simpan. 3. Saat panel "Mengunduh…", putuskan koneksi (Playwright `context.setOffline(true)`; di dunia nyata Wi-Fi putus di tengah request).
- **Diharapkan:** panel menampilkan "Koneksi ke server terputus — mencoba lagi otomatis (n/4)…" lalu melanjutkan sendiri setelah koneksi pulih (D-060, `RETRY`).
- **Terjadi:** panel diam di "10 dari 150 lampiran · Mengunduh…" selama > 5 menit, tanpa pesan coba ulang maupun error. DB staging: 140 PENDING, tidak ada yang diklaim → panggilan proses berikutnya tidak pernah sampai ke server.
- **Akar masalah:** request proses yang sedang berjalan saat koneksi putus **tidak pernah selesai** (tidak ditolak, tidak dijawab). `fetch` peramban tidak punya batas waktu, jadi `process.isPending` tetap `true` dan antrean panel tidak pernah berlanjut; coba ulang otomatis (D-060) hanya bereaksi pada request yang **gagal**, bukan yang menggantung.
- **Perbaikan:** `PROCESS_TIMEOUT` 60 dtk di `apps/web/src/features/employee/import/api.ts` — panggilan proses/ulangi memakai `AbortSignal.timeout`; `TimeoutError` dilaporkan api-client sebagai gagal terhubung (status 0) → ditangani `RETRY` panel (backoff + jitter). 60 dtk jauh di atas kerja server per panggilan (±8 dtk + satu lampiran).
- **Test pencegah:** `apps/web/tests/import-attachments.test.tsx` "koneksi menggantung → batas waktu panggilan habis → dicoba ulang otomatis, tidak macet (BUG-003)" (merah sebelum perbaikan: macet; hijau sesudah) + Playwright B-04b (`QA/2026-10-12-staging-gel4/b-lampiran-ui.ts`: satu request ditahan tanpa jawaban → coba ulang setelah ±64 dtk → lanjut) ✔ lokal `QA/2026-10-12-bug-003-lokal/`.
