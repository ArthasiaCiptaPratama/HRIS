# Rencana Uji — Multi-Perusahaan & Cakupan PT (Tahap 2, D-039/D-040, 2026-09-30)

- **Ruang lingkup:** tabel perusahaan + `employees.company_id` (ACP dari migrasi, PT dummy CD2 di seed), cakupan PT untuk HR_ADMIN di modul employee & iam, direktori per PT, penugasan PT akun HR oleh SA, pindah PT (riwayat + audit), web: pemilih perusahaan, kolom/field Perusahaan, dialog "Atur PT".
- **Aturan yang diuji:** D-039, D-040 (+ rincian a–e), PLAN §4.3 (cakupan perusahaan), §4.4/D-034 (ganti role), PROMPT §5 (404 untuk data di luar cakupan).
- **Di luar lingkup:** CRUD perusahaan & master data (Tahap 3), import (Tahap 4), laporan/payroll per PT, staging (menunggu rilis + seed CD2).
- **Lingkungan:** lokal Linux — PostgreSQL 17 (migrasi + seed ulang), API :3000 + web :5173, login Supabase staging sungguhan (SA/HR/MGR/EMP); Playwright Chromium 1440×900 & 390×844. Satu perubahan data lokal (penugasan PT akun HR) dikembalikan lewat UI.
- **Kriteria lulus:** semua P1 & P2 LULUS; typecheck, lint, boundaries, `db:check`, seluruh test, build hijau; konsol bersih.
- **Suite:** [cases/employee.md](../cases/employee.md) TC-EMP-072 s.d. TC-EMP-078; [cases/administrasi.md](../cases/administrasi.md) TC-ADM-011 s.d. TC-ADM-014.
